## Qué hace

Muestra información útil bajo cada comodín:  
cuánto multi o fichas da ahora, contadores,  
probabilidades, cartas que lo activan...  
Controles: clic derecho (o B) para  
ocultar/mostrar; clic izquierdo (o arriba)  
para plegar/desplegar.
